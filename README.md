## Getting Started

To set up the project locally, you need to install (if not already the case) some dependencies. To get a local copy up and running follow these steps.

### Prerequisites

* Python interpreter

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/lock94656/unittests.git
   ```
2. Open a terminal or Python interpreter
